# Hospital Readmission Analysis Dashboard (Excel Project)

#### &#x20;**Project Overview**



This project focuses on analyzing hospital patient data to identify patterns in readmissions, patient demographics, and treatment factors. The goal is to provide insights that help improve patient care and reduce unnecessary hospital readmissions.



&#x20;**Objectives**

Analyze patient readmission trends

Identify high-risk patient groups

Evaluate factors affecting hospital stay and readmission

Provide actionable recommendations to reduce readmission rates



&#x20;**Tools \& Technologies**



Microsoft Excel

Pivot Tables

Pivot Charts

Excel Formulas (COUNTIFS, AVERAGEIFS, etc.)

Data Cleaning \& Transformation



&#x20;**Key Analysis Performed**



Readmission analysis by age group

Length of stay by medical specialty

Impact of medication changes on readmission

Demographic analysis (Race \& Gender)

KPI calculations (Readmission Rate, Average Stay, etc.)



&#x20;**Key Insights**

Older patients (60+) have higher readmission rates

Certain specialties show longer hospital stays

Medication changes impact readmission likelihood

Emergency admissions contribute significantly to readmissions



&#x20;**Recommendations**

Implement follow-up care for high-risk patients

Focus on reducing readmissions in critical departments

Improve discharge planning and patient monitoring

Optimize medication management processes



&#x20;**Challenges Faced**

Handling missing or inconsistent data

Choosing appropriate charts for visualization

Creating meaningful KPIs from raw data



**Dashboard Features**

Interactive and visual dashboard

KPI summary section

Multiple charts for trend analysis

Clean and structured layout



&#x20;**Conclusion**



This project demonstrates how Excel can be effectively used for healthcare data analysis. The insights derived can help hospitals improve patient outcomes and reduce operational costs.
